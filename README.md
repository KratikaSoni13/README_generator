# AI README Generator
An AI-powered Streamlit application that automatically generates professional README files for GitHub repositories using the OpenAI API.

Features
Generate polished README files from any public GitHub repository
Fetch repository metadata directly from GitHub
Analyze project structure and languages used
Multiple README writing styles
Simple Streamlit-based user interface
Uses OpenAI GPT models for high-quality documentation generation
Tech Stack
Python
Streamlit
OpenAI API
GitHub API
Requests
Python Dotenv

How It Works
User enters a GitHub repository URL
The app fetches:
Repository metadata
Languages used
File structure
Repository information is sent to the OpenAI API
GPT generates a professional README
User can copy or download the generated README
